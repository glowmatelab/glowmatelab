## Signature interactions

| Interaction | Essence | Motion spec |
| :--- | :--- | :--- |
| **Neon hover** | **Presence:** soft cyan bloom | `ease-out 180ms • glow + 2px lift` |
| **Glyph pulse** | **Companion:** subtle heartbeat | `cubic-bezier(.2,.9,.2,1) 900ms • 3% scale` |
| **Panel reveal** | **Precision:** clean slide + blur | `ease 240ms • 12px translate + 6px blur` |

> Sources: Use 60–70% cyan glow, keep z‑motion under 4px, and limit blur to preserve sharpness.
